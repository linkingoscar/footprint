💡 微信小程序开发与连接指引
  1. 微信小程序端完整工程源码位于项目根目录下的 miniapp/ 目录中；
  2. 使用微信开发者工具打开 miniapp/ 即可进行预览与编译调试；
  3. 在小程序 miniapp/utils/api.js 中已配置向本服务的 /api/wechat/login 及 /api/records 传输足迹；
  4. 若在局域网测试真机调试，请在小程序中设置 API Base 为电脑本地内网 IP。
