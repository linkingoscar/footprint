快速开始

3步开始记录你的美好生活

📋 开始使用
1
选择模式与地图服务
在首页切换旅行/美食/情侣模式；需要地图时到「设置」选择高德、百度、腾讯或必应并填入 Key
2
添加记录
点击「添加记录」按钮，上传照片、搜索地点或使用照片 EXIF 自动定位
3
查看足迹
在首页查看照片墙、足迹地图、时间线、统计报告和轨迹回放
💡 提示

没有 API Key 也可以使用本地记录、照片墙、时间线和统计；带 GPS 的 JPEG 照片仍可在纯前端模式下自动定位。

📷

添加记录

上传照片，记录美好瞬间

🖼️ 上传照片

支持多种方式添加照片：

1
本地/文件夹上传
点击「本地上传」标签，选择照片或文件夹，也可以直接拖拽批量上传
2
相册、拍照和链接
手机端可从相册选择或拍照；也可以切换到「链接添加」输入单个或多行图片 URL
📍 设置地点

为记录添加位置信息：

1
自动提取
手机拍摄的 JPEG 照片通常包含 GPS 和拍摄时间，前端或后端都会自动提取
2
搜索地点
输入地点名称，系统会按当前地图服务搜索并匹配坐标
✅ 小技巧

使用手机拍照可以获得最准确的位置信息！

系统设置

配置API和个性化选项

🗺️ API配置

支持高德、百度、腾讯和必应地图，任选一个服务即可启用地图与地点搜索：

1

2
填入配置
在设置页面选择地图服务、填入 API Key，并保存到本地或同步到后端

❓

常见问题

解答你的疑惑

❓ 如何获取地图 API Key？
可选择高德、百度、腾讯或必应地图。到对应开放平台注册应用，并创建浏览器端或 Web JS API 可用的 Key。
❓ 照片没有位置信息？
截图和网络图片通常没有GPS信息，可以手动搜索地点或输入坐标。
❓ 数据会丢失吗？
纯前端模式数据保存在浏览器本地；完整服务模式可保存到后端 SQLite/PostgreSQL。建议定期导出备份。
❓ 支持哪些图片格式？
支持JPG、PNG、GIF、BMP、WebP等常见格式。
❓ 可以多人使用吗？
当前以个人使用为主，可通过完整服务模式、多端访问同一后端，或导出/导入 JSON 文件共享数据。
⚠️ 注意

数据保存在浏览器本地，清除浏览器数据会丢失记录。建议定期导出备份！
